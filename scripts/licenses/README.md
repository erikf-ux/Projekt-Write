# Standardtexte für Lizenzen

`scripts/third-party-licenses.mjs` nimmt diese Texte für Komponenten, deren Paket keine eigene Lizenzdatei enthält. Die Urheber nennt dann der Eintrag in `THIRD-PARTY-NOTICES` (aus den Paketangaben). MPL-2.0 und Apache-2.0 sind die offiziellen Texte (aus Debian `common-licenses`), MIT und BSD-3-Clause die SPDX-Vorlagen.
